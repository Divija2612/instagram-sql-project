# Instagram SQL Project
A database project that models the core backend of an Instagram-like social media platform using SQL, focusing on relational database design and query-based analysis. A data analytics dashboard is also built using Streamlit, Plotly and Power BI to visualize user activity such as posts, likes, comments, and followers.
## Project overview
This project demonstrates the design and implementation of a relational database system to store and analyze Instagram-style user activity. It covers key social media entities such as users, posts, likes, comments, and followers, showcasing practical SQL skills and database concepts.
## Features
- User database visualization
- Likes per post analysis
- Comments per post insights
- Follower distribution
- Interactive charts using Plotly
- Real-time data fetching from PostgreSQL
## Tech Stack
- **Database:** PostgreSQL
- **Backend:** Python, SQLAlchemy
- **Data Analysis:** Pandas
- **Visualization:** Plotly
- **Frontend:** Streamlit
- **Business Intelligence:** Power BI (DAX, KPI Cards, Pie & Line Charts)
To see the instagram dashboard through streamlit run "streamlit run app.py" in a python based environment.
